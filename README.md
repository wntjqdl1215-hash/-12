# 📈 주식 뉴스 한눈에 (MVP)

관심 종목 뉴스를 **한 화면에 모아서**, 어려운 내용은 **초보자도 알 수 있게 쉽게 요약**해주는 정보 앱.
**예측해서 사라고 하지 않습니다.** 정보만 깔끔하게 정리해주고, **판단은 사용자가 직접** 합니다.

> 시장 포지셔닝: "AI가 찍어주는 예측 서비스"(레드오션, 규제 리스크)가 아니라
> "흩어진 정보를 한 화면에 모아주는 개인용 대시보드"로 차별화.

---

## 핵심 기능 (이번 MVP)

- **관심 종목 입력** → 이름(삼성전자) 또는 6자리 코드(005930) 모두 가능
- **뉴스 자동 수집** → 네이버 금융에서 종목별 뉴스 크롤링
- **초보자용 쉬운 요약** → 기사 본문을 2~3줄로 정리
- **어려운 용어 풀이** → 영업이익·HBM·공매도 등 어려운 단어에 설명 칩(탭하면 뜻 표시)
- **본문 보기** → 원문 전체는 버튼으로 새 탭에서 따로 열기
- **반응형** → 모바일 1열 / PC 2열 자동 전환

---

## 실행 방법

```bash
# 1) 의존성 설치 + 서버 실행 (한 번에)
bash run.sh

# 또는 수동으로
pip install -r requirements.txt
cd backend && python3 app.py
```

브라우저에서 **http://localhost:8000** 열기.
같은 와이파이의 휴대폰에서 보려면 `http://<PC의 IP>:8000`.

### (선택) Claude AI로 더 자연스러운 요약

API 키 없이도 규칙 기반 요약으로 동작합니다. 더 매끄러운 요약을 원하면:

```bash
pip install anthropic
export ANTHROPIC_API_KEY=sk-...
cd backend && python3 app.py
```

## 구조

```
backend/
  app.py          # Flask 서버: /api/news API + 프론트엔드 서빙 (TTL 캐시 5분)
  crawler.py      # 네이버 금융 뉴스 크롤러 (+ 본문 추출)
  summarizer.py   # 초보자 요약 + 용어 사전 (Claude 선택, 규칙 기반 폴백)
  stocks.py       # 종목명 <-> 코드 변환
  sample_data.py  # 오프라인/차단 환경용 샘플 뉴스
frontend/
  index.html / style.css / app.js   # 반응형 단일 페이지
```

## API

```
GET /api/news?symbols=삼성전자,000660&limit=5
```

종목별 뉴스 목록 + 요약 + 용어 설명 + 원문 링크(JSON) 반환.

## 동작 메모

- **인터넷이 열린 환경**(개인 PC 등): 네이버 금융에서 실제 뉴스를 가져옵니다.
- **네트워크가 차단된 환경**(일부 클라우드 샌드박스): 자동으로 번들 샘플 데이터로 폴백해
  화면·요약 기능을 그대로 시연합니다.

## ⚠️ 면책

본 서비스는 **정보 제공 목적**이며 투자 권유가 아닙니다. 투자 판단과 책임은 본인에게 있습니다.
국내에서 종목 추천·매매신호를 제공하려면 유사투자자문업 신고 등 규제 확인이 필요합니다.
